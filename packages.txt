# This file is the CORE install only. Optional features pull heavier deps and
# are installed on request (see install.sh flags), so a plain install stays lean:
#   --with-airplay-audio  -> shairport-sync          (AirPlay audio receive)
#   --with-youtube        -> nodejs npm mpv yt-dlp    (YouTube DIAL receive)
#   --with-all            -> both
# AirPlay video-out + the control center use pyatv, installed isolated via pipx
# (no apt packages) on every install when pipx is present.
#
# The UI is a GNOME Quick Settings extension (GJS, ships with gnome-shell) —
# no extra packages needed.
#
# The .deb (from v0.7.5, packaging/deb/) is deliberately thinner: Depends:
# python3 (kast-airplay) + jq (nearly every kast verb pipes through it) only;
# everything else above is Recommends, same list as this file's core install.
# No new packages beyond what's already here — see docs/RELEASE-SIGNING.md's
# ".deb" section and Makefile's `deb` target for the exact split. (Caught by
# an isolated-container install test: without jq, `kast update` aborts
# silently under set -e/pipefail before reaching any of its own logic.)
